# ACML 2026 Tutorial Website

**Tutorial:** Advances in Multi-Modal Time Series: From Forecasting to Reasoning  
**Conference:** ACML 2026, Melbourne, Australia  
**Tutorial date:** 1 December 2026  

This is a static GitHub Pages-ready website. It uses plain HTML/CSS/JavaScript and has no build step.

## Preview locally

Open `index.html` directly in a browser, or run:

```bash
python -m http.server 8000
```

then visit `http://localhost:8000`.

## Publish with GitHub Pages

1. Create a repository, e.g. `acml2026-multimodal-timeseries`.
2. Upload the contents of this folder to the repository root.
3. In **Settings → Pages**, choose **Deploy from a branch**.
4. Select `main` and `/ (root)`.

## Design rationale

The structure combines the concise tutorial-first hierarchy of the KDD FM4TS page with the clearer sticky navigation and section organization of the ACML OE-Agent site. The visual identity is original and tailored to multi-modal time series rather than copying either reference site.
