# ACML 2026 Tutorial Website

A minimal static website for **Advances in Multi-Modal Time Series: From Forecasting to Reasoning**.

## GitHub Pages

Place these files at the repository root and deploy from `main` / `/ (root)`.

## Update before the tutorial

Edit `index.html` to add:
- exact tutorial room and start time;
- slide URL;
- Hands-on 1 Colab URL;
- Hands-on 2 Colab URL;
- code/resource links.

No build step is required.
